## Implementation Plan

1. `django-admin startapp playbooks` at repo root; add `"playbooks"` to `INSTALLED_APPS`.
2. Implement models:
   - `Playbook` — `name`, `slug` (unique), `description`, `is_system_seed`, timestamps, optional `created_by` FK.
   - `PlaybookVersion` — FK `playbook`, `version_number` (unique per playbook), `workflow_md`, `change_summary`, `created_at`, optional `created_by`.
   - `PlaybookVariable` — FK version, `sort_order`, `name`, `abbrev`, `calculating`, `interpreting`, `hover`, `dimensions` JSONField (list of strings).
   - `PlaybookTable` — FK version, `sort_order`, `entity` (TextChoices aligned with journey: unit_of_work, increment, milestone, sprint, contributor), `slicer`, `dimensions` JSONField.
3. `UniqueConstraint` on `(playbook, version_number)` for versions.
4. Register models in Django admin (stacked inlines for Variable/Table on Version optional).
5. `makemigrations` + migrate locally.
6. Factories in `tests/factories.py`.
7. Unit tests: unique constraint violation; create graph playbook→version→variables preserves counts.
