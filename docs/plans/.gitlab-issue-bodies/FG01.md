## Implementation Plan

1. Add `sitrep/models.py` (or `sitrep/models/frago.py` + package `__init__` export): **`Frago`** with:
   - FK `project` → `ingestion.Project`
   - `title` (required), `body_md` (markdown source)
   - Optional FK `affected_variable` → `playbooks.PlaybookVariable` (nullable = global narrative per journey)
   - `effective_from`, `effective_to` (DateField nullable)
   - `enabled` (bool, default True)
   - `revoked_at` (DateTimeField nullable) — soft revoke per journey
   - Audit: `created_at`, `updated_at`, optional `created_by`, `updated_by` FKs to `AUTH_USER_MODEL`
2. Constraints / validation: document in code/docstring — **revoked** rows must not be toggled back to enabled (enforce in service or `clean()`).
3. Register `Frago` in `sitrep/admin.py`.
4. Migrations + `manage.py check`.
5. Factories in `tests/factories.py` if pattern exists.
6. **`tests/unit/test_frago_models.py`**: create FRAGO; FK optional variable; revoked nullable; project required.
