## Interfaces
```python
class ScriptedLLM(LLM):
    def __init__(self, responses: list[LLMResponse]):
        self._responses = iter(responses)
        self.calls: list[dict] = []
    def generate_with_tools(self, messages, tools, system_blocks) -> LLMResponse:
        self.calls.append({"messages": messages, "tools": tools, "system_blocks": system_blocks})
        return next(self._responses)
```
Exposed as `@pytest.fixture` named `scripted_llm_factory` — takes a list of responses,
returns a `ScriptedLLM` instance.
