# Blueprint T-65b — GJLR-TOOLS part 2: playbook + sitrep tools + build_executor

## Design
Add the three remaining read tools and the `build_executor` factory function
that wires all five tools into a `ToolExecutor` and returns it.

All three tools follow the same envelope contract established in T-65a.
`build_executor` is the single construction point that T-66 (`GjallarhornAgent`)
and T-67 (`execute_plan`) both call.

## Interfaces
```python
def build_executor(user, project) -> ToolExecutor:
    executor = ToolExecutor(user=user, project=project)
    executor.register('list_commits', list_commits)
    executor.register('get_contributor_activity', get_contributor_activity)
    executor.register('get_active_playbook', get_active_playbook)
    executor.register('get_active_situational_awareness', get_active_situational_awareness)
    executor.register('list_active_fragos', list_active_fragos)
    return executor
```

`list_active_fragos(project_id, at_dt)`: `Frago` where `is_active=True`,
`effective_from ≤ at_dt`, `effective_to IS NULL OR effective_to > at_dt`.
