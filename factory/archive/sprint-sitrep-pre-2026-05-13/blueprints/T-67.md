# Blueprint T-67 — GJLR-EXECUTE-PLAN: execute_plan task + state-machine helpers

## Design
Two deliverables in one task:
1. Add state-machine helpers to `ExecutionPlan` (extends T-60's model):
   `mark_started`, `mark_completed`, `mark_failed`, `mark_paused_for_retry`,
   `update_progress`, `get_next_pending_step`. Add `InvalidStateTransitionError`.
2. Implement the `execute_plan` Celery task with the resilience matrix from SAO §17.5.

`execute_plan` loop: `get_next_pending_step()` → `agent.execute_single_step()` → repeat.
On `RateLimitError/TimeoutError/OSError`: `mark_paused_for_retry` + `self.retry(countdown=...)`.
On other exceptions: `mark_failed`. On all steps done: `mark_completed()` +
`# TODO(sitrep-generate): _persist_sitrep_from_plan(plan)` stub.

`_build_agent_for_plan` is a private helper (uses `create_agent()` from factory);
tests patch it to inject `GjallarhornAgent(ScriptedLLM([...]), build_executor(...))`.
