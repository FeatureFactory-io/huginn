# Blueprint T-60 — GJLR-MODELS: models + migrations

## Design
Create the five Django models that every downstream Gjallarhorn task depends on.
Field definitions in SAO §17.5 (ExecutionPlan, PlanStep) and §17.11 (Conversation,
Message) are **normative** — copy them verbatim. SitRep goes in `sitrep/` app;
the four gjallarhorn models go in `gjallarhorn/models/`.

No logic beyond model fields, `Meta`, and `__str__`. State-machine helpers
(`mark_started` etc.) land in T-67, not here.

## Files touched
- `sitrep/models/sitrep.py` — new `SitRep` model
- `sitrep/models/__init__.py` — export SitRep
- `sitrep/admin.py` — register SitRep read-only
- `sitrep/migrations/000N_sitrep.py` — new migration
- `gjallarhorn/models/conversation.py` — Conversation + Message
- `gjallarhorn/models/execution_plan.py` — ExecutionPlan (fields only)
- `gjallarhorn/models/plan_step.py` — PlanStep
- `gjallarhorn/models/__init__.py` — exports
- `gjallarhorn/migrations/0001_initial.py`
- `huginn/settings/base.py` — add `'gjallarhorn'` to INSTALLED_APPS if absent
- `tests/sitrep/test_sitrep_model.py` — write tests first
- `tests/gjallarhorn/test_execution_plan_model.py` — write tests first

## Interfaces / contracts
- `SitRep.Meta.constraints`: `UniqueConstraint(fields=['project','to_dt'], name='uq_sitrep_project_to_dt')`
- `PlanStep.Meta.constraints`: `UniqueConstraint(fields=['plan','order'], name='uq_plan_step_order')`
- `ExecutionPlan.status` default = `'pending'`; choices: `pending|running|completed|failed|waiting_retry`
- `SitRep.notable_activity`: `JSONField(default=list)`

## Risks
- `gjallarhorn` app must be in `INSTALLED_APPS` before migrations run.
- `SitRep → Frago` M2M: confirm `Frago` model path (`sitrep.Frago`) before writing FK string.
- Do NOT add `mark_started` or any method beyond `__str__` — T-67's scope.
